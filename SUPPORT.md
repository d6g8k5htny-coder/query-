# Help with Query

For installation, lookup, or verification problems, [open an issue here](https://github.com/d6g8k5htny-coder/query-/issues/new).
Include the full commit (`git rev-parse HEAD`), Python version, operating system,
command, and expected versus observed result. A small public example is best.
Remove credentials and private catalog entries before posting.

For a wrong catalog entry, use the [catalog repository](https://github.com/d6g8k5htny-coder/meta-framework/issues).
For a mathematical question, follow the artifact's recorded repository and
scope, or begin with the [research reading guide](https://d6g8k5htny-coder.github.io/main/site/).
Query verifies source identities; it does not adjudicate mathematical claims.

See [the citation file](CITATION.cff) to cite this tool. Include the exact commit
in your reference and cite the mathematical source separately. The package's
declared version is not evidence of a published release or DOI.

For a suspected security problem, follow [the security reporting guidance](SECURITY.md).
